מה אומרים מעמדים בפורומים מקצועיים?

אתגרים אמיתיים ומצוקות יומיומיות שמעלים מעמדים ומעצבים מול וורד ואינדיזיין — וכיצד TypesetOK נבנתה לפתור אותם.

פורום מעמדים (פרוג) כאב: קריסת עימוד בוורד
״הלקוח ביקש בסך הכל להוסיף משפט אחד בעמוד 40... וכל העימוד של ספר בן 350 עמודים בוורד פשוט התפרק לחלוטין. הערות השוליים ברחו, הכותרות קפצו לעמוד הבא, והייתי צריך לעבור עמוד-עמוד מחדש כאילו התחלתי מאפס.״
הפתרון ב-TypesetOK:

מודל עמודים עצמאי עם מנגנון נעילת מקטעים (Page Pinning). שינוי מקומי בפסקה נפתר מקומית ואינו מקריס את שארית הספר.

פורום לתורה (עימוד ספרי קודש) כאב: ריבוי מפרשים באינדיזיין
״לעמד ש״ס או חומש עם רש״י ותוספות באינדיזיין זה מסע ייסורים. אין כלי מובנה לריבוי טקסטים מקבילים שזורמים יחד. נאלצים לרכוש פלאגינים באלפי שקלים, וכל עדכון גרסה של Adobe משבית את התוספים ומעכב הוצאה של חודשים.״
הפתרון ב-TypesetOK:

פותר רב-תזרימי (Talmud Solver) מובנה בליבת התוכנה — סנכרון רציף בין טקסט ראשי ומפרשים באותו עמוד ובכפולות, ללא צורך בשום תוסף חיצוני.

הרצת בדיקות מקוד המקור (Rust Engine)

פרויקט TypesetOK נמצא בשלב פיתוח הליבה (Core Engine). מפתחים וחוקרים מוזמנים לשבט את המאגר ולהריץ את חבילת הבדיקות הרשמית:

# 1. Clone repository
git clone https://github.com/TypesetOK/typesetok.git
cd typesetok

# 2. Build Rust workspace crates
cargo build --workspace

# 3. Run all 58 core unit tests
cargo test --workspace

# 4. Verify formatting & clippy
cargo fmt --check
cargo clippy --workspace --all-targets -- -D warnings
דרישות סביבה: Rust 1.85+ עם כלי הניהול הרשמי Cargo.

דו״ח ארכיטקטורה הנדסי: TypesetOK (TOK)

עקרונות היסוד הארכיטקטוניים

1. עצמאות מוחלטת של מודל המסמך (TDM): מודל המסמך מנותק לחלוטין מ-DOM, מתגיות HTML ומחוקי CSS של הדפדפן. כל המבנים הסמנטיים כתובים ב-Rust טהור.

2. עקרון ה-Pre-Pagination: מנוע ה-UI אינו מורשה לנחש שבירות עמודים או חלוקת טורים. ליבת ה-Rust מבצעת את כל חישובי Knuth-Plass ומעבירה דפים שכבר עברו חלוקה מראש.

3. צינור PDF דואלי: שכבת תצוגה מבוקרת ומהירה למסך לצד צינור קדם-דפוס נייטיב עצמאי לחלוטין ב-Rust המפיק PDF/X-1a תקני עם 100% K Black ו-BleedBox של 3 מ"מ.

4. שכבת סמן וירטואלי: עקיפת כשלי contenteditable המובנים בדפדפנים בעזרת שכבת Canvas שקופה וסמן וירטואלי.

5. תמיכה מובנית במסמכי ענק: אלגוריתם עימוד אינקרמנטלי מבוסס התכנסות (Convergence Pagination) ווירטואליזציה מלאה של 3 עמודים פעילים בלבד.
